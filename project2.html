About the Project

This project is an interactive data visualization dashboard that analyzes flight delays across the United States from February 2017 to July 2022. The dashboard was designed to help users identify patterns and key factors contributing to flight delays by delay type, airline, and airport location. Through clear and engaging visualizations, users can easily compare airline performance, explore yearly delay trends, and understand the main causes behind operational delays in the aviation industry.

Additional Features

  • Interactive filters to select time range, delay type, and airline.
  • Dynamic tooltips displaying detailed information for each data point on the map.
  • Responsive dashboard design for seamless navigation across devices.
  • Integrated visualization combining trends, distributions, and geographical insights.

Main Features

  • Total keterlambatan berdasarkan kategori (Arrival, Carrier, Weather, Security, dsb).
  • Distribusi keterlambatan per maskapai (Carrier).
  • Tren persentase delay maskapai dari 2017-2022.
  • Peta interaktif sebaran keterlambatan berdasarkan lokasi bandara.
