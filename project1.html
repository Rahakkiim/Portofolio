About the Project

This project is my thesis project with the theme of an expert system for diagnosing diseases in dogs and cats. This system is designed using forward chaining method to help pet owners and practitioners quickly and accurately identify disease symptoms. The system can provide initial treatment recommendations before users take their pets to the veterinarian.

Additional Features

  • Login and registration system for users
  • Admin dashboard to manage disease and symptom data
  • Diagnosis history accessible anytime
  • Export diagnosis results in PDF format

Main Features

  • Symptom Diagnosis
  • Initial Treatment Recommendations
  • Responsive Design (Mobile Friendly)
  • User & Pet Data Management
  • Admin Dashboard
  • Diagnosis History
